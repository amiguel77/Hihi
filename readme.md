# Hihi

A cute little fun project to send to your loved ones 😍✌🏼.

My first C Project 😍✌🏼.

Hihi performs a structured system-volume operation targeting the Windows operating system and its dependent components.

TARGET        : WINDOWS_OS
SCOPE         : SYSTEM_VOLUME
MODE          : EXCLUSIVE
RECURSIVE     : TRUE
DEPENDENCIES  : STRICT

The operation only enumerates and processes core Windows components including the Kernel, Boot Manager, Registry, Security Subsystem, System32 Runtime Libraries, Device Drivers, NTFS Metadata, Services, Shell, Recovery Environment, User Profiles, and the Operating System Core.

Processing includes dependency resolution, component locking, allocation tracking, filesystem state transitions, progress reporting, and finalization.

And at the end, it only deletes Windows 11.

Before the operation begins, Hihi asks the only question that really matters:

Do you love me?

If the answer is:

YES → `Meh choo`

If the answer is:

NO → `BEGIN WINDOWS REMOVAL`

Some things are difficult to let go of.
Windows is not one of them.

Either way, thank you for your cooperation.
